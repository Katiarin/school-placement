1. Свои варианты размещения

Можно добавить несколько школ в разные кварталы. Вместимость — целое положительное число мест.

    2. Автоматический подбор квартала

    Проверяются все кварталы территории: каждый вариант — одна школа заданной вместимости. Строки таблицы — независимые варианты, а не одновременное размещение школ. Рекомендуются только кварталы с населением и дефицитом мест; остальные проверенные кварталы остаются в таблице для справки. ★ — рекомендованный квартал: при равном сокращении дефицита по району выбирается квартал с наибольшим дефицитом мест.

    Проверено 0 из 0 кварталов территории

    3. Сравнение вариантов

    Можно сравнить два или три варианта. В ненужном варианте выберите «— не сравнивать»; прочерк в любом из двух кварталов варианта 2 отключает весь вариант.

      Население и вместимость школ по кварталам — расчётные значения практики 2, а не официальная статистика. Приложение сравнивает обеспеченность населения местами в школах для разных вариантов размещения по кварталам. Оно не выбирает земельный участок и не оценивает возможность строительства — для этого требуется отдельное градостроительное обоснование.
